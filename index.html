    Generate tree from gene content
    Upload a Newick tree file (.nwk/.newick/.tree) to visualize phylogenetic relationships.
    Source

    A table with one row per gene (or domain) per genome: a molecule / accession column and a gene column. Genomes are compared by the genes they share (Jaccard distance) and a tree is built from those distances.

    The sequences of an alignment layer are compared site by site (p-distance: the share of differing sites where both have a residue; gaps are left out) and a tree is built from those distances. Bootstrap replicates resample the columns and label each clade with the percentage of replicates that contain it.

    Method Neighbor-Joining: does not assume a molecular clock (as R's ape::nj)
