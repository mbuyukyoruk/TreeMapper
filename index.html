PhyloTree + Metadata Viewer

Upload a Newick tree and an optional CSV/TSV with branch‑tip metadata (e.g., protein length). Align a numeric column (e.g., protein length) as a bar track next to branch tips. Pan/zoom, collapse clades, export SVG — all client‑side.

Upload a Newick tree file (.nwk/.newick/.tree) to visualize phylogenetic relationships.
Upload a gene/domain dataframe file (.csv/.tsv) to generate a phylogenetic tree based on Jaccard distance.
